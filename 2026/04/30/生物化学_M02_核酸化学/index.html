核酸化学

一、核酸概述与化学组成

1. 分类与分布

类型 说明
DNA（脱氧核糖核酸） 遗传信息的贮存和携带者
真核生物 主要在细胞核，少量在线粒体和叶绿体
原核生物 位于拟核，单条双链环状DNA
RNA（核糖核酸） 参与遗传信息的传递和表达，主要分布在细胞质

特例： RNA病毒中RNA是遗传物质；类病毒是游离的RNA；核酶是具催化活性的RNA

2. 核苷酸：核酸的基本结构单位

组成三要素：戊糖、碱基、磷酸

连接方式：戊糖 + 碱基 → 核苷；核苷 + 磷酸 → 核苷酸；核苷酸之间 → 多核苷酸链（核酸）

3. DNA与RNA的组成区别

区分点 DNA RNA
戊糖 D-2-脱氧核糖 D-核糖
碱基 A, G, C, T A, G, C, U
共有碱基 A, G, C A, G, C

4. 细胞内重要的游离核苷酸衍生物

类型 代表物 功能
多磷酸核苷酸 ATP（通用供能）、UTP、CTP、GTP 能量代谢
环式单核苷酸 cAMP、cGMP 第二信使，信号转导
辅酶类核苷酸 NAD⁺、NADP⁺、FAD、CoA 脱氢酶辅酶

二、DNA的分子结构

1. 一级结构

  • 定义：指单链DNA分子上4种脱氧核苷酸的排列顺序及连接方式
  • 连接键：3’,5’-磷酸二酯键（共价键）
  • 方向性：5’末端（游离磷酸基）→ 3’末端（游离-OH）

2. 二级结构（Watson-Crick双螺旋模型）

  • 碱基组成规律（Chargaff定律）：A=T, G=C；(A+G)=(T+C)
  • 结构要点：
    • 两条反向平行的多聚脱氧核苷酸链（一条5’→3’，另一条3’→5’）
    • 右手螺旋；骨架在外（磷酸-脱氧核糖），碱基在内
    • 碱基互补配对：A=T（2个氢键），G≡C（3个氢键）
    • 螺旋直径2nm，螺距3.4nm（10bp/圈），碱基间距0.34nm
  • 稳定力：
    • 纵向：碱基堆积力（主要稳定力）
    • 横向：氢键

3. 三级结构

  • 超螺旋：正超螺旋（盘绕方向与双螺旋方向一致）和负超螺旋（自然界常见）
  • 核小体（真核染色质的基本结构单位）：组蛋白核心八聚体（H2A, H2B, H3, H4各两分子）+ 缠绕的DNA（约200bp）+ 组蛋白H1

三、RNA的分子结构

1. RNA与DNA的异同

相同 不同
基本单位单核苷酸，连接键均为3’,5’-磷酸二酯键 RNA为单链（局部双链），戊糖为核糖，含U不含T

2. 三种主要RNA

类型 含量 结构特点 功能
mRNA 3%~5% 真核：5’端m7G帽子，3’端PolyA尾巴 转录遗传信息，作为翻译模板
tRNA ~15% 含稀有碱基最多（如DHU, Ψ），三叶草形 转运氨基酸，识别密码子
rRNA ~80% 分子量最大，与蛋白质构成核糖体 构成核糖体，蛋白质合成的场所

3. tRNA的结构细节（二级结构：三叶草形）

结构 含有的特殊碱基 功能
氨基酸臂 -CCA-OH 连接氨基酸的位点
二氢尿嘧啶臂 (DHU臂) 二氢尿嘧啶(DHU) 氨酰-tRNA合成酶的识别结合部位
反密码子臂 反密码子（3个碱基） 识别mRNA上的密码子（摆动假说）
TΨC臂 假尿嘧啶(Ψ) 与核糖体结合的部位

四、核酸的理化性质

1. 一般性质

  • 形态：DNA（白色纤维状），RNA（白色粉末状）
  • 溶解性：微溶于水，钠盐易溶；不溶于有机溶剂
  • 黏度：DNA黏度极高（双螺旋刚性），变性或降解后黏度下降
  • 紫外吸收：最大吸收峰 260nm
    • 纯DNA的A260/A280 = 1.8；纯RNA = 2.0
    • A260=1.0相当于50μg/mL dsDNA或40μg/mL ssDNA/RNA

2. 变性、复性与分子杂交

概念 说明
变性 氢键断裂，双链解开成单链（磷酸二酯键不断裂，一级结构不变）
表现 增色效应（A260升高）、黏度下降、浮力密度升高
复性 变性条件解除后，单链恢复双链结构
分子杂交 不同来源的单链DNA或RNA根据碱基配对原则形成杂合双链
