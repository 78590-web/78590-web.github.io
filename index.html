3. 维生素

一、维生素的分类

类别 包含 特点
水溶性维生素 B1, B2, PP, B6, 泛酸, 生物素, 叶酸, B12, 硫辛酸, 维生素C 体内不易储存，易随尿排出，不易中毒
脂溶性维生素 维生素A、D、E、K 随脂类吸收，在肝脏储存，摄入过多会中毒

二、水溶性维生素（重点：辅酶形式与功能）

核心逻辑：水溶性维生素 = 辅酶/辅基 = 参与代谢反应

1. 维生素B₁（硫胺素 / 抗脚气病维生素）

  • 活性形式：🔥焦磷酸硫胺素 (TPP)
  • 功能：α-酮酸氧化脱羧酶的辅酶；转酮酶的辅酶；抑制胆碱酯酶活性
  • 缺乏症：🔥脚气病（手足麻木、心力衰竭、下肢水肿）、末梢神经炎

2. 维生素B₂（核黄素）

  • 活性形式：🔥FMN（黄素单核苷酸）、FAD（黄素腺嘌呤二核苷酸）
  • 功能：氧化还原酶的辅基，作为递氢体（双递氢体）传递氢和电子
  • 缺乏症：口角炎、唇炎、阴囊炎

3. 维生素PP（尼克酰胺 / 抗癞皮病维生素）

  • 活性形式：🔥NAD⁺（辅酶Ⅰ）、NADP⁺（辅酶Ⅱ）
  • 功能：多种脱氢酶的辅酶，递氢体（单递氢体）
    • NAD⁺：参与氧化途径（电子受体）
    • NADPH：参与还原途径（电子供体）
  • 缺乏症：🔥癞皮病（3D症状：皮炎、腹泻、痴呆）

4. 维生素B₆（吡哆醇/醛/胺）

  • 活性形式：磷酸吡哆醛 (PLP)、磷酸吡哆胺 (PMP)
  • 功能：🔥转氨酶和氨基酸脱羧酶的辅酶；参与血红素合成
  • 缺乏症：对痉挛、皮肤及中枢神经系统损害

5. 泛酸（遍多酸）

  • 活性形式：🔥辅酶A (CoA)、酰基载体蛋白 (ACP)
  • 功能：酰基转移酶的辅酶，传递酰基（如乙酰CoA）
  • 缺乏症：未发现

6. 生物素（维生素B₇）

  • 活性形式：生物胞素
  • 功能：🔥多种羧化酶的辅酶，参与CO₂的固定和羧化反应
  • 缺乏症：怠倦、厌食、呕吐

7. 叶酸

  • 活性形式：🔥四氢叶酸 (FH₄ / THF)
  • 功能：一碳单位转移酶的辅酶，🔥一碳单位载体，参与嘌呤/嘧啶合成
  • 缺乏症：🔥巨幼红细胞贫血

8. 维生素B₁₂（钴胺素 / 抗恶性贫血维生素）

  • 活性形式：甲基钴胺素、5’-脱氧腺苷钴胺素
  • 功能：参与甲基转移；分子内重排
  • 缺乏症：🔥巨幼红细胞贫血（恶性贫血）

9. 硫辛酸

  • 活性形式：硫辛酸
  • 功能：α-酮酸脱氢酶系的辅助因子，同时传递氢和酰基
  • 缺乏症：未发现

10. 维生素C（L-抗坏血酸）

  • 特性：强还原剂，对热不稳定
  • 功能：
    • 参与羟化反应：促进胶原蛋白合成；参与胆固醇羟基化
    • 参与氧化还原反应：保护巯基酶；将Fe³⁺还原为Fe²⁺促进铁吸收；保护VitA、VitE免遭氧化
  • 缺乏症：🔥坏血病

三、脂溶性维生素

核心逻辑：脂溶性维生素构成活性分子或激素，参与宏观生理调控

1. 维生素A（视黄醇 / 抗干眼病维生素）

  • 活性形式：11-顺视黄醛
  • 来源：动物肝脏；β-胡萝卜素（维生素A原，存在于胡萝卜等绿叶蔬菜）
  • 功能：
    • 🔥视觉：构成视紫红质（暗视觉）。光中分解，暗中再合成
    • 上皮组织：维持结构完整，防止角质化
    • 抗癌防癌
  • 缺乏症：🔥夜盲症、干眼病、皮肤干燥

2. 维生素D（抗佝偻病维生素）

  • 种类：D₂（麦角钙化醇）、D₃（胆钙化醇）
  • 活性形式：🔥1,25-(OH)₂-VitD₃（需经肝、肾羟化）
  • 来源：肝、蛋黄；7-脱氢胆固醇经紫外线照射产生D₃
  • 功能：🔥调节钙磷代谢（促进肠、肾对钙磷吸收，促进骨骼钙化）
  • 缺乏症：儿童—🔥佝偻病；成人—🔥软骨病

3. 维生素E（生育酚）

  • 功能：
    • 🔥抗氧化作用（核心）：对抗生物膜磷脂中不饱和脂肪酸过氧化，清除自由基，保护生物膜，🔥抗衰老
    • 维持生殖机能：防习惯性流产
    • 促进血红素代谢：防营养性贫血
  • 缺乏症：肌肉萎缩、神经退行性病变

4. 维生素K（凝血维生素）

  • 活性形式：氧化型（需被还原成氢醌型才能发挥催化活性）
  • 功能：促进肝脏合成凝血因子（Ⅱ、Ⅶ、Ⅸ、Ⅹ）及抗凝血因子（蛋白C、S）
  • 来源：绿叶蔬菜；肠道细菌合成
  • 缺乏症：凝血障碍（易出血）

酶

一、酶的本质与特点

1.1 酶的概念

  • 定义：由活细胞合成的、对其特异底物起高效催化作用的生物催化剂
  • 化学本质：主要——蛋白质（绝大多数）；少数——RNA（核酶，Cech 1981年发现）、抗体酶、某些DNA
  • 考点提示：核酶不是蛋白质，是唯一的非蛋白酶

1.2 酶的作用特点

共性：

  • 反应前后质和量不变
  • 只催化热力学允许的反应
  • 不改变反应的平衡点
  • 降低反应的活化能

特性（核心考点）：

  1. 极高的催化效率：比非催化高10⁸～10²⁰倍，比一般催化剂高10⁷～10¹³倍
  2. 高度的专一性（特异性）：一种酶只作用于一种或一类底物
  3. 活性的可调节性：受底物/产物浓度、激素、共价修饰等调节
  4. 高度的不稳定性：易受理化因素影响而失活

二、酶的组成与结构

2.1 按分子组成分类

类型 说明
单纯酶 仅由蛋白质构成，水解产物只有氨基酸
结合酶（全酶） 酶蛋白 + 辅助因子 = 全酶
  • 酶蛋白：决定反应的特异性（专一性）
  • 辅助因子：决定反应的类型与性质

辅酶 vs 辅基（高频考点）：

辅酶 辅基
结合方式 结合疏松，非共价键 结合紧密，共价键
透析除去 可以（使酶丧失活性） 不可以
  • 辅助因子来源：金属离子（Cu²⁺, Zn²⁺等）；小分子有机物（多为B族维生素衍生物，如NAD⁺, FAD, CoA等）

2.2 按分子结构分类

类型 说明
单体酶 仅一条多肽链（三级结构），分子量13,000-35,000
寡聚酶 含2个或以上亚基（非共价键），分子量35,000-几百万
多酶复合体 多种酶靠非共价键契合，依次催化连续反应
多功能酶/串联酶 一条多肽链上具有多种不同催化功能

2.3 酶的活性中心

  • 定义：酶分子表面必需基团集中并形成一定空间构象的区域
  • 结合部位：决定酶的专一性
  • 催化部位：决定酶的催化能力
  • 常见必需基团：组氨酸咪唑基、丝氨酸羟基、半胱氨酸巯基、天冬氨酸羧基

三、酶的催化机理与专一性

3.1 酶的专一性分类

结构专一性：

  • 绝对专一性：只能催化一种底物发生一种反应（如脲酶）
  • 相对专一性（族/基团专一性）：作用于一类化合物或一种化学键

立体异构专一性：

  • 旋光异构专一性：只作用于一种旋光异构体（如L-氨基酸氧化酶）
  • 几何异构专一性：只作用于顺式或反式

3.2 专一性假说

学说 说明
锁钥学说 酶与底物结构严格互补，刚性匹配
诱导契合学说（重点） 酶活性中心具有柔性，底物诱导酶构象改变，使有关基团正确排列定向，互相契合
三点附着模型 解释立体异构专一性，底物需3个结合点都匹配

3.3 酶高效催化的机制

中间产物学说：E + S ⇌ ES → E + P

高效催化因素：

  • 邻近与定向效应：提高有效浓度，反应基团正确取位
  • 底物形变与诱导契合：底物敏感键受张力形变，接近过渡态
  • 酸碱催化：如His咪唑基（pK 6.0-7.0）在生理pH下既是质子供体又是受体
  • 共价催化：形成不稳定的共价中间物
  • 低介电区域（微环境）：活性中心疏水，不利于水化膜形成

四、酶促反应动力学（计算与分析核心）

4.1 底物浓度 [S] 的影响

曲线：矩形双曲线

阶段 特点
[S]低 V与[S]成正比（一级反应）
[S]增高 V增加减慢（混合级反应）
[S]极高 V达最大值Vmax不变（零级反应，酶被饱和）

4.2 米氏方程与米氏常数

米氏方程：
$$v = \frac{V_{max}[S]}{K_m + [S]}$$

米氏常数 Km（绝对核心考点）：

  • 定义：反应速度达到最大反应速度一半时的底物浓度
  • 意义：是酶的特征物理常数（只与酶性质、底物、pH、温度有关，与酶浓度无关）
  • Km越小，亲和力越大；Km越大，亲和力越小

计算考点：

[S] v
[S] = 0.1Km v = 9.1% Vmax
[S] = 0.5Km v = 33.3% Vmax
[S] = 2Km v = 67% Vmax

双倒数作图（Lineweaver-Burk）：1/V对1/[S]作图，y轴截距=1/Vmax，x轴截距=-1/Km

4.3 其他因素的影响

  • 酶浓度 [E]：[S]饱和时，V与[E]成正比
  • 温度：双重影响（有最适温度，非特征常数）
  • pH：有最适pH（非特征常数）
  • 胃蛋白酶最适pH ~1.8，肝精氨酸酶 ~9.8

4.4 抑制剂的影响（必考）

抑制剂类型 Km Vmax 例子
竞争性抑制 不变（表观Km↑） 不变 磺胺类药物（竞争对氨基苯甲酸）
非竞争性抑制 不变 减小 重金属离子
反竞争性抑制 减小 减小 —

五、酶的活性调节

调节方式 说明
别构调节 效应物与别构部位结合，调节酶活性
共价修饰调节 磷酸化/去磷酸化（最常见）、乙酰化、甲基化等
酶原激活 无活性的酶原 → 有活性的酶（切割肽键，构象改变）
同工酶 催化相同反应，但分子结构和理化性质不同
